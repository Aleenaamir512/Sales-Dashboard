# 📊 Superstore Sales Dashboard | Power BI & Python

## 📌 Project Overview

This project analyzes **Superstore sales data** using two different approaches:

1. **Power BI** – An interactive business intelligence dashboard
2. **Python** – Programmatic data analysis and visualization using a Jupyter Notebook

The goal of the project is to analyze sales performance, profitability,
regional performance, product categories, and monthly sales trends while
demonstrating both BI dashboard development and Python-based data analysis.

---

## 🎯 Project Objectives

- Analyze overall sales and profitability
- Monitor important sales KPIs
- Compare sales performance across regions
- Analyze product category performance
- Identify top-performing products
- Explore monthly sales trends
- Demonstrate the same business analysis using Power BI and Python

---

# 🟡 Power BI Version

The Power BI version provides an interactive dashboard where users can
explore sales performance using filters, KPIs, and visualizations.

## 📊 Key KPIs

- **Total Sales:** 2,297,201
- **Total Profit:** 286,397
- **Total Quantity:** 37,873
- **Profit Margin:** 12.47%

## 📈 Dashboard Features

### Region & Year Filters
Interactive slicers allow users to analyze the dashboard according to
different regions and years.

### Sales by Category
Shows the contribution of:

- Technology
- Furniture
- Office Supplies

### Sales by Region
Compares sales performance across Central, East, South, and West regions.

### Top Product Purchases
Identifies products generating the highest sales.

### Monthly Sales Trend
Shows how sales performance changes throughout the year.
